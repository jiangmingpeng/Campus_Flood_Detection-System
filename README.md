# 校园大面积积水应急排水实验台 V1.0（FreeCAD 概念模型）

一句话：把原 drawio 俯视图做成一米级**参数化实体模型**（800×500×8 mm 底板，14 个分组），
A/B/C/D 四个积水分区相互独立、水面高度可现场调，配移动泵 + 回收水箱 + 干燥电子区 + 3 处传感器 + 3 条软管。

> 状态：V1.0 已交付｜最后一次修订 **2026-11-22**（V1.1：A 区改浅坑、P1 改挡水台阶、5 张视图按新配方重出）
> 校核：**硬性越界/干涉 0 处**、登记豁免 41 处；宏内 `check_model()` 与 `layout_params.py` 两套独立实现结果一致。

## 2. 三步上手

1. FreeCAD → 宏 → 宏编辑器 → 打开 `.FCMacro` → 执行（Ctrl+F5）→ 自动重建并保存 `.FCStd`、切等轴测视图。
2. 想改尺寸：改文件头【1. 参数区】，或在 `Parameters` 电子表格里改输入行后重跑宏（宏会先读回表里的值）。
3. 只想调水位、不想重建：改 `A_WATER_LEVEL` 等输入行 → Ctrl+R，水面 Z 由公式绑定自动升降。

## 5. 还需要你拍板的一件事

P1 这一版做成了**凸起挡水台阶**（136×68×15，台面 23 = A 区路缘顶），泵 110×60 放在台面上（X 余 13/13、Y 余 4/4），
**不是"下沉 110 mm 的凹位"**：这个位置南边被浅水盘（y≤252）、北边被 A 区地坪（y≥320）夹住，进深最多只有 68 mm，物理上挖不到 110。
（改成凸台后其实也不需要 110：泵是人工搬上台面，不存在"沉下去"的需求，而且台面与 A 路缘同高，刚好形成"A 区漫水 → 台阶挡水 → 溢流进浅水盘"的路径。）
若你仍要真正的 110 mm 凹位（泵横着停），只能改布局：① 浅水盘东移约 150 mm，或 ② 凹位移到 x 15~78（净宽 63，仍不够）。
两条都没擅自做，你定了我再改。详见 `02_交付说明与验证.md` 第 5 节。
